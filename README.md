# Cultura Alternativa — Portal editorial

Site estático para Netlify, mantido no GitHub.

## Publicação
Copie os arquivos para a **raiz do repositório** `cultura-alternativa`, preservando os nomes. No Netlify, use a branch `main` e o diretório de publicação `.`. Não há comando de build.

## Páginas
- `index.html`: home
- `blog.html`: artigos
- `artigo-identidade.html`: exemplo de artigo (substituir)
- `documentario.html`: episódios
- `sobre.html`: apresentação
- `faca-parte.html`: cadastro
- `obrigado.html`: confirmação
- `privacidade.html`: transparência de dados — **completar contato antes de divulgar**
- `styles.css`: estilos compartilhados

## Antes de divulgar a landing page
1. Definir e publicar um e-mail de contato real em `privacidade.html`.
2. Verificar a Política de Privacidade e quem gerenciará os dados.
3. Testar uma inscrição no Netlify e conferir o formulário em Forms.
4. Verificar exigências da LGPD para tratamento, armazenamento e retirada de consentimento.
5. Planejar o processo de envio de e-mails; **Netlify Forms apenas recebe os cadastros**.

## Nota
Textos e títulos de episódios são provisórios. Não incorporar a fonte Quivana Personal Use em site público sem verificar a licença. O Pages CMS será configurado em etapa posterior.
