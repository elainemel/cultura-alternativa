Privacidade.

Entenda quais dados o formulário coleta e como são utilizados.

Para dúvidas sobre o uso de seus dados, entre em contato pelo e-mail noctivivium@gmail.com.

Quais dados coletamos?

Nome, endereço de e-mail e confirmação de consentimento informados voluntariamente na página Faça Parte.

Para qual finalidade?

Para organizar o interesse em receber atualizações do portal, episódios e conteúdos relacionados. Os dados não serão vendidos.

Onde ficam armazenados?

Os envios são recebidos pelo Netlify Forms e ficam disponíveis à pessoa responsável pela conta do projeto, conforme as configurações da plataforma.

Contato, acesso e exclusão

Para solicitar acesso, correção ou exclusão dos dados, ou retirar o consentimento, envie uma mensagem para noctivivium@gmail.com.

Este texto é um modelo inicial, não uma análise jurídica conclusiva. Confirme as práticas reais antes de coletar dados de visitantes.
